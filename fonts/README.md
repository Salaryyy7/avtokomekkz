# Fonts

Inter-Variable.ttf: Inter variable (optical size and weight), downloaded from the Google Fonts repository, with Cyrillic support. License: Inter-OFL.txt.

Oswald-Variable.ttf: Oswald variable, downloaded from the Google Fonts repository, with Cyrillic support. License: Oswald-OFL.txt.

Sources:
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/oswald

Druk Bold was not provided. Oswald is a temporary display fallback, not an imitation or a supplied copy of Druk. Replace the fallback with a properly licensed Cyrillic Druk Bold file when available.
